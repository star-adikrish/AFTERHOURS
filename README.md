# AFTERHOURS – Teen Arcade

I created AFTERHOURS – Teen Arcade because I wanted to build something fun, interactive and different from an ordinary website. The idea was to create a virtual arcade where teens could take a break from their daily routines, explore games and enjoy themselves.

My journey of building AFTERHOURS involved a lot of experimenting, learning and improving. I started with a basic idea and gradually turned it into a fully interactive gaming website. Along the way, I worked on designing the interface, experimenting with colours and animations, fixing coding errors and making the overall experience smoother. There were times when things didn't work as expected, and I had to go back, understand the problem and try different solutions.

I developed four mini-games and introduced features like XP, coins, achievements, a leaderboard and progress saving to make the experience more engaging. I also designed a moving neon background and added interactive elements to give the website a modern arcade-style feel.

One of the most interesting parts was figuring out how to connect all these features and make them work together. This project helped me improve my coding, debugging and problem-solving skills while also teaching me how much planning and creativity goes into building a website.

AFTERHOURS is more than just a gaming website for me. It represents an idea that I started from scratch, experimented with and gradually brought to life. I'm proud of how it turned out, and this project has motivated me to keep building, learning and exploring more possibilities in web development.
